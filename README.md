# JARVIS LLM

Module indépendant d'intelligence artificielle destiné à une future intégration à JARVIS CORE et JARVIS VOICE.

## État du projet

**Phase 0 — étude de faisabilité uniquement.** Aucun développement applicatif n'est encore autorisé.

## Exigences de départ

- Fonctionnement local et hors ligne, sans API cloud obligatoire.
- Architecture hybride : LLM local, RAG documentaire, réponses structurées, mémoire locale et actions autorisées.
- Premières cibles : POCO X8 Pro (principal) et Redmi Pad SE (mode allégé).
- Protections thermiques, batterie et mémoire ; aucun root ni contournement des sécurités Android.
- Profils de puissance ÉCO, ÉQUILIBRÉ, AUTO et PLEINE PUISSANCE pour un futur matériel adapté.
- Modèles et moteurs interchangeables ; JARVIS CORE et JARVIS VOICE restent inchangés pendant les études.

## Première mission

Produire une analyse de faisabilité, une architecture proposée, une comparaison des modèles/moteurs et une feuille de route avant d'écrire du code.
